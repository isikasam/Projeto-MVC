# Projeto MVC

Projeto desenvolvido para demonstrar o padrão de arquitetura MVC utilizando HTML, CSS e JavaScript.

## Estrutura

- index.html
- style.css
- TarefaModel.js
- TarefaView.js
- TarefaController.js
- app.js

## Componentes

### Model
Responsável pelos dados.

### View
Responsável pela interface.

### Controller
Responsável pela comunicação entre Model e View.
